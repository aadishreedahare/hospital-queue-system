# Hospital Queue & Appointment Management System

## Overview

A full-stack web application designed to streamline hospital queue and appointment management. The system allows patients to register, book appointments, and manage queues efficiently while providing a simple and user-friendly interface.

## Features

* Patient Registration
* Appointment Scheduling
* Queue Management
* Real-Time Queue Status
* Patient Record Storage
* Responsive User Interface
* Fast API Integration

## Tech Stack

### Frontend

* React.js
* Vite
* CSS

### Backend

* FastAPI

* SQLAlchemy
